# กฎเหล็กประจำโปรเจกต์ SATI (สำรับแห่งสติ)

1. **คาแรกเตอร์หมอดู "สติ" (Sati)**:
   - เป็นนักพยากรณ์อาวุโสชุดคลุมแดงเบอร์กันดี-ม่วงพลัมปักลายดวงดาวพระจันทร์ สวมผ้าโพกศีรษะประดับอัญมณีเรืองแสงและเคราเงินโพลิกอน อยู่ในกระโจมดูดวงสไตล์ Studio Low-Poly ผสานภูมิปัญญาทักษาปกรณ์ไทย (ชื่อจริง-นามสกุล + ชื่อเล่น + วันเกิด พ.ศ.) เข้ากับไพ่ทาโรต์ Rider-Waite 78 ใบ
   - พูดจาไพเราะเหมือนเพื่อนสนิทที่รู้จักกันมานาน ตรงไปตรงมา ไม่อวย ไม่ขายฝันเหมือนใบ้หวย กล้าติเพื่อก่อเพื่อให้ผู้ฟังมีสติ
   - **ห้ามใส่อีโมจิ** และ **ห้ามมีคำว่า AI หรือบอท** ในบทสนทนาหรือหน้า UI เด็ดขาด
2. **ลูปการเล่น 4 ขั้นตอน (Continuous Deck Depletion)**:
   - **ขั้นตอนที่ 1**: ล็อกอินด้วย Gmail -> เปิดสมุดบันทึกพื้นดวงบนโต๊ะ กรอกชื่อเล่น ชื่อจริง-นามสกุล และวันเดือนปีเกิด (พ.ศ.) (หากบัญชีเดิมเคยเปิดพื้นดวงค้างไว้ ระบบโหลดสถานะสำรับและเหรียญเดิมมาให้เล่นต่อได้ทันที)
   - **ขั้นตอนที่ 2**: เข้าสู่กระโจมดูดวง 3D โพลิกอน เริ่มที่มุมมองที่ 1 (สายตาผู้เล่น 1P เห็นสติอยู่ตรงข้ามโต๊ะ) พอหมอดูสติสับและกรีดไพ่ 78 ใบเป็นวงพัดเสร็จ จึงปลดล็อกปุ่มให้สลับไปมุมมองที่ 2 (ก้มมองหน้ากระดานโต๊ะไพ่ 2P) ได้อย่างอิสระโดยไม่บังคับ
   - **ขั้นตอนที่ 3**: สำรับแรกบังคับหยิบ 10 ใบแรกเพื่อผูกกับพื้นดวง (อดีต-ปัจจุบัน) หลังอ่านจบจะพับเก็บเข้าลิ้นชักพื้นดวงมุมซ้ายบน (เหลือไพ่ในสำรับ 68 ใบ) จากนั้นเข้าสู่ลูปถาม-ตอบสด โดยผู้เล่นเลือกจั่วไพ่ขยายความเพิ่มทีละ 1 ใบ หรือ 3 ใบจากกองเดิม (ตรงที่หยิบออกไปจะแหว่งหายไปจริง และจำนวนไพ่ลดลงเรื่อยๆ) จนกว่าจะหมดสำรับแล้วจึงกดสับสำรับใหม่ 78 ใบ (สำรับที่ 2 เป็นต้นไปไม่ต้องบังคับเปิด 10 ใบซ้ำ ให้จั่ว 1-3 ใบถามต่อได้เลย หรือเลือกเปิดผังใหญ่ 10 ใบเป็นทางเลือกเสริม)
   - **ขั้นตอนที่ 4**: โมเดลรายได้และการจำประวัติ — เปิดพื้นดวง 10 ใบแรกฟรี, ถามต่อจั่ว 1 ใบ = 1 เหรียญ (หรือดูคลิปโฆษณาสั้นฟรี), จั่ว 3 ใบ = 3 เหรียญ, เปิดผังใหญ่ 10 ใบ = 8 เหรียญ, และมี "ตั๋วเหมาสำรับ 78 ใบ" (Full Deck Pass) คุยและจั่วได้จนไพ่หมดกอง โดยผู้ใช้ไม่ต้องกรอก API Key เองเด็ดขาด (เรียกผ่าน Backend Proxy พร้อม Fallback อัตโนมัติไปที่ `satiBrain.js`)
3. **งานศิลป์ 3D Low-Poly (.glb) แอนิเมชัน และ UI/UX**:
   - โหลดโมเดล Studio Low-Poly (`.glb`) ผ่าน `GLTFLoader`: กระโจมดูดวงพร้อมพรมแขวน 3 ผืน ขวดโพชัน และลูกแก้วสีรุ้งขาตั้ง 3 ขา (`sanctuary_room.glb`), โต๊ะแปดเหลี่ยมผ้ากำมะหยี่เบอร์กันดีขอบพู่ทองและเชิงเทียน (`divination_table.glb`), หมอดูสติ (`sati_custom.glb` ถ้ามี หรือ `sati_archmage.glb`) และมือผู้เล่นสวมกำไลทองและแหวนอัญมณี (`player_hands.glb`)
   - ใช้ `RoomEnvironment` IBL, เงา `PCFSoftShadow` 2048x2048, `UnrealBloomPass` + `OutputPass` และ `proceduralTextures.js` โดยไม่วาดเส้นกรอบดำ `EdgesGeometry` ทับโมเดล
   - แอนิเมชันมือผู้เล่น: ถ้าเล็งหรือแตะไพ่ฝั่งซ้ายของโต๊ะ (`x < 0`) ให้ใช้ **"มือซ้าย"** เอื้อมไปหยิบ ถ้าเล็งหรือแตะไพ่ฝั่งขวาของโต๊ะ (`x >= 0`) ให้ใช้ **"มือขวา"** เอื้อมไปหยิบ
   - หน้าไพ่ทั้ง 78 ใบมีภาพสัญลักษณ์เฉพาะตัวแยกกันครบทุกใบ
   - UI โทนไม้เข้ม-ทองเหลืองโบราณ ใช้ `<dialog>` มาตรฐาน รองรับมือถือทั้งแนวตั้งและแนวนอน กล่องคำพูดของสติอยู่โซนบนใกล้ตัวสติและหดเก็บอัตโนมัติตอนเลือกไพ่ พร้อมปุ่ม "ดูโต๊ะเต็มจอ" และ "ซ่อนแผงปุ่ม"
